Build MyRegulars, a personal web app for remembering the names and meaningful details of people you regularly encounter at the places you frequent — cafés, gyms, bars, and anywhere else you're a regular. The app uses a bring-your-own-datastore model where each user's data lives in their own private GitHub Gist (one Gist equals one vault), making vaults portable, shareable via link or QR code, and entirely user-owned with no hosted backend. The full product requirements are in `docs/PRD.md` and the high-fidelity design handoff — including exact design tokens, component anatomy, interaction specs, and motion details — is in `docs/design/README.md`, with a clickable React prototype at `docs/design/MyRegulars Prototype.html` and reference screenshots in `docs/design/screenshots/`. The stack is Next.js App Router with TypeScript strict mode, Tailwind CSS, shadcn/ui, NextAuth for GitHub OAuth (scope `gist`), the GitHub Gists REST API for persistence, Framer Motion for animations, Geist and Geist Mono fonts, and Lucide icons. Data is organized as Vault → Location → Group (optional) → Person, persisted as a single JSON file per Gist with optimistic local updates and a debounced PATCH. The desktop layout is a three-pane shell (268px sidebar, flex center pane, 360px conditional right rail) while mobile uses master-detail navigation with a FAB, bottom sheets, and swipe-to-log gestures. Both light and dark themes are driven by CSS variables as defined in the design handoff. Read-only mode is enforced at the datastore level whenever the authenticated user doesn't own the opened Gist, surfacing a persistent banner with a clone CTA rather than any app-level permission logic. The v1 scope excludes PWA/offline support, push notifications, tags, activity feeds, multi-writer collaboration, native apps, and photo hosting.
